# PiFollow – רחפן קטן שעוקב אחרי אדם, מבוסס Raspberry Pi

פרויקט זה מתכנן ומיישם מערכת **person-following drone** (רחפן שעוקב אוטומטית אחרי אדם)
בגרסה **קטנה, זולה ובטוחה** המבוססת על Raspberry Pi כמחשב נלווה (companion computer),
במקום הרחפנים הגדולים והיקרים שרואים בסרטונים ישנים.

> ⚠️ **חשוב:** רחפנים הם כלי טיס. קראו את [docs/safety-legal.md](docs/safety-legal.md)
> לפני שאתם בונים או מטיסים. יש חוקים (רת"א בישראל) לגבי רישוי, גובה, מרחק ופרטיות.

## איך זה עובד בקצרה

```
מצלמה → זיהוי אדם (Raspberry Pi) → חישוב סטייה → בקרי PID → פקודות מהירות → בקר טיסה → מנועים
```

1. מצלמה על הרחפן מצלמת וידאו.
2. ה-Raspberry Pi מזהה את האדם בפריים (מיקום + גודל התיבה).
3. המערכת מחשבת "שגיאה": כמה האדם סטה שמאלה/ימינה, קרוב/רחוק, גבוה/נמוך.
4. בקרי PID ממירים את השגיאה לפקודות תנועה (yaw, קדימה/אחורה, גובה).
5. הפקודות נשלחות לבקר הטיסה דרך MAVLink, והרחפן עוקב.

## שתי דרכים למימוש

| | מסלול קל (מומלץ להתחלה) | מסלול מלא (Build) |
|---|---|---|
| רחפן | DJI Tello / Tello EDU | רחפן DIY עם בקר טיסה ArduPilot/PX4 |
| חיבור | WiFi (Tello SDK) | UART/MAVLink בין Pi לבקר הטיסה |
| בטיחות | מגני פרופלור, מקורה, קל | דורש failsafe, geofence, בדיקות |
| עלות | ~500-700 ₪ | ~1500-3000 ₪ |
| קוד | `src/drone/tello_drone.py` | `src/drone/mavlink_drone.py` |

## מבנה הפרויקט

```
docs/           תכנון מלא: ארכיטקטורה, רכיבים, חיווט, בטיחות
src/vision/     זיהוי ומעקב אחרי אדם (OpenCV)
src/control/    בקרי PID ולוגיקת המעקב
src/drone/      ממשקים לרחפן (MAVLink / Tello)
src/main.py     לולאה ראשית
config/         הגדרות ניתנות לכיוונון
```

## התחלה מהירה (סימולציה, בלי חומרה)

```bash
pip install -r requirements.txt
python -m src.main --drone sim --source 0   # 0 = מצלמת המחשב
```

זה יריץ את צינור הזיהוי + הבקרה במצב סימולציה ויציג את פקודות התנועה על המסך,
בלי לשלוח שום דבר לרחפן אמיתי. זו הדרך הבטוחה לבדוק את המערכת.
