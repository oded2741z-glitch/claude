# גיבוי: היומן החכם, לפני אפליקציית הדמות

בתיקייה הזו נמצא `AI_Journal_App.py` כפי שהיה ב־25 באוגוסט 2026 (קומיט `6574bf1`), לפני הבקשה לבנות אישיות שאפשר לדבר איתה.

זה **יומן חכם**: כותבים בו כל יום, מסמנים משימות, מצב רוח וכוסות מים, ומקבלים תובנה מ־Gemini. אין בו דמות ואין שיחה.

## מה יש בו

- יומן לפי ימים וחודשים, עם תובנת AI בארבעה סגנונות (Wellness Coach, Psychologist, Spiritual Guide, Tough Love Mentor)
- רשימת משימות: מחיקה של כל משימה בנפרד, וקו חוצה על משימה שבוצעה
- הצפנה אמיתית של היומן עם סיסמה
- שמירה בטוחה: אם השמירה נכשלת, מופיעה הודעה במקום כישלון שקט
- הקראה והכתבה באנגלית

## קובץ אחד, בלי `core.py`

הגרסה הזו עומדת בפני עצמה, ואפשר להעתיק אותה לבד לכל מקום ולהריץ.

```
python -m pip install -r requirements.txt
python AI_Journal_App.py
```

## היא חולקת את אותו יומן עם הגרסה העדכנית

שתי הגרסאות שומרות לאותה תיקייה (`%APPDATA%\AI_Journal` ב־Windows) ובאותו פורמט, וזה נבדק בפועל בשני הכיוונים, גם כשהיומן מוצפן. כלומר:

- מה שכותבים באחת מופיע בשנייה.
- הסיסמה זהה בשתיהן.
- אפשר לעבור ביניהן בלי לאבד כלום.

## ההבדל מהיומן שבתיקייה הראשית

ההתנהגות זהה. היומן בתיקייה הראשית השתנה פעם אחת מאז: הקוד של השמירה וההצפנה הועבר ל־`core.py`, כדי שאפליקציית הדמות תוכל להשתמש בו. לכן הוא צריך את `core.py` לידו, והגרסה כאן לא.

התיקייה הזו היא תמונת מצב. תיקונים עתידיים ייכנסו לגרסה שבתיקייה הראשית ולא לכאן.
