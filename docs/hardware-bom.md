# רשימת רכיבים (Bill of Materials)

המחירים הם הערכה גסה (₪, 2025) ומשתנים. שני מסלולים:

## מסלול א' – הכי פשוט: DJI Tello EDU + Raspberry Pi

מתאים למי שרוצה להתחיל מהר, בבית, בלי הלחמות ובלי לבנות רחפן.

| רכיב | תפקיד | מחיר משוער |
|---|---|---|
| DJI Tello EDU | רחפן קטן עם SDK ומגני פרופלור | ~600 ₪ |
| Raspberry Pi 4 (2/4GB) | מריץ את הזיהוי, שולח פקודות ב-WiFi | ~350 ₪ |
| כרטיס microSD 32GB | מערכת הפעלה | ~40 ₪ |
| ספק כוח ל-Pi | הפעלה | ~50 ₪ |

יתרונות: קל, בטוח (מקורה, מגנים), ה-Tello כבר יציב. חיסרון: הזיהוי רץ על ה-Pi
"מהצד" ושולח פקודות ב-WiFi (לא על הרחפן עצמו), טווח וזמן טיסה מוגבלים.

## מסלול ב' – רחפן DIY עם מחשב נלווה על הסיפון

רחפן אמיתי שנושא את ה-Pi ואת המצלמה, ה"מוח" טס יחד איתו.

### שלדה והנעה
| רכיב | תפקיד | מחיר |
|---|---|---|
| שלדה 5" (או 4" למשקל נמוך) | מסגרת | ~120 ₪ |
| 4× מנועים brushless (~2306) | הנעה | ~200 ₪ |
| 4× ESC / 4-in-1 ESC | בקרת מנועים | ~200 ₪ |
| 4× פרופלורים (+ מגנים!) | הנעה | ~40 ₪ |
| סוללת LiPo 4S | חשמל | ~120 ₪ |

### מוח ובקרה
| רכיב | תפקיד | מחיר |
|---|---|---|
| בקר טיסה עם ArduPilot/PX4 (למשל Matek/Pixhawk-class) | ייצוב, GPS, failsafe | ~350-700 ₪ |
| **Raspberry Pi Zero 2 W** | מחשב נלווה, קל משקל | ~150 ₪ |
| מודול GPS + מצפן | החזקת מיקום, RTL | ~120 ₪ |
| Pi Camera v2/v3 (CSI) | וידאו | ~150 ₪ |
| ממיר מתח (BEC) 5V ל-Pi | הזנת ה-Pi מהסוללה | ~40 ₪ |
| מקלט RC + שלט | שליטה ידנית + kill switch | ~250 ₪ |

### אופציונלי – מאיץ AI (מומלץ מאוד למעקב חלק)
| רכיב | תפקיד | מחיר |
|---|---|---|
| Google Coral USB Accelerator | מזרז זיהוי ל-30+ FPS | ~350 ₪ |
| או Raspberry Pi AI HAT (Hailo) | מאיץ על הסיפון | ~400 ₪ |

**סה"כ מסלול ב':** בערך 1500-3000 ₪ תלוי בבחירות.

## המלצת בחירה
- **מתחילים / הוכחת היתכנות:** מסלול א' (Tello). מריצים את `tello_drone.py`,
  לומדים את לוגיקת המעקב בבטחה.
- **פרויקט "אמיתי" בחוץ:** מסלול ב' עם Pi Zero 2 W + בקר ArduPilot + Coral.
  זה מה שהכי דומה למערכת שבסרטון, אבל בקנה מידה קטן ובר-שליטה.

## שיקול משקל (קריטי לרחפן קטן)
כל גרם נחשב. Pi Zero 2 W (~11g) עדיף בהרבה על Pi 4 (~46g) לרחפן קטן. אם המשקל
גבוה מדי — הזמן טיסה צונח והרחפן פחות זריז. שקלו את כל המערכת לפני טיסה ראשונה.
