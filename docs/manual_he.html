Display Room

מערכת לניהול חדר מסכים: מחשב בקרה אחד שולט על מסכי תצוגה מרובים, כל מסך מציג עד ארבעה מקורות וידאו במקביל.
display_controller.exe
viewer.exe
display_configurator.exe

1מה המערכת עושה

המערכת בנויה משלוש תוכנות שעובדות יחד. מחשב אחד מוגדר כבקר (Controller), והוא מפעיל ושולט על חלונות תצוגה (Viewer) שרצים במסך מלא על שאר המסכים.

התוכנהמה היא עושהמתי מפעילים
display_configurator.exe מגדיר את המסכים, את רשימת מקורות הווידאו ואת ההגדרות הכלליות. פעם אחת בהתקנה, ואחר כך רק כשמשנים חומרה או מקורות.
display_controller.exe לוח הבקרה. מפעיל ומכבה מסכים, קובע מה מוצג בכל ריבוע, שומר ומעלה סצנות. בכל יום עבודה — זו התוכנה הראשית.
viewer.exe חלון התצוגה עצמו במסך מלא. לא מפעילים ידנית — הבקר מפעיל אותו אוטומטית.
חשוב: כל שלושת הקבצים וקובצי ההגדרות חייבים לשבת באותה תיקייה. התוכנות קוראות את ההגדרות מהתיקייה שממנה הן רצות.

3התקנה ראשונה — סדר הפעולות

  1. להעתיק את כל הקבצים לתיקייה אחת על מחשב הבקרה.
  2. להפעיל את display_configurator.exe ולהגדיר מסכים, מקורות והגדרות (פרקים 4–6).
  3. ללחוץ SAVE CONFIG ו-SAVE SETTINGS ולסגור את הכלי.
  4. להפעיל את display_controller.exe ולהעלות את המסכים (פרק 7).
חומת האש של Windows: בהפעלה הראשונה של הבקר יופיע חלון אישור רשת. יש לאשר — הבקר מריץ שרת פנימי בפורט 5000 שדרכו כל המסכים מסתנכרנים.

4הכלי: לשונית Displays Map

כאן מגדירים אילו מסכים פיזיים קיימים ואיך הם מסודרים.

  1. DETECT MONITORS — סורק את המסכים המחוברים למחשב וממלא את הטבלה לבד. זו הדרך המומלצת.
  2. לחיצה כפולה על שורה בטבלה פותחת חלון עריכה — אפשר לשנות את השם (Alias) של המסך לשם משמעותי כמו "מסך ראשי" או "קיר שמאל".
  3. VISUAL EDITOR — עורך ויזואלי לסידור המסכים ברשת, כך שהתצוגה בבקר תשקף את הסידור הפיזי בחדר.
  4. SET AS PRIMARY — מסמן את השורה הנבחרת כמסך הראשי.
  5. SAVE CONFIG — שומר. בלי זה שום שינוי לא נשמר.
CLEAR ALL מוחק את כל השורות הנבחרות. אין ביטול לפעולה.

5הכלי: לשונית Stream Targets

רשימת מקורות הווידאו שיהיו זמינים לבחירה בבקר.

  • ממלאים Target Name (השם שיופיע ברשימה) ו-Stream URL (הכתובת של המקור) ומוסיפים לטבלה.
  • DELETE SELECTED מוחק את השורה הנבחרת.
  • לחיצה על שורה טוענת אותה לשדות לעריכה.
אם הכתובת נכתבת בלי http:// — התצוגה תוסיף את זה לבד.

6הכלי: לשונית Settings

הגדרהמשמעות
Show Viewer Header מציג בראש חלון התצוגה סרגל עם שם המקור וידית לשינוי גודל. לתצוגת קיר נקייה — לכבות.
Loading Animation האנימציה שמוצגת בריבוע שעדיין אין לו מקור. אפשר לבחור מתוך רשימה (ELTA, גלים, מכ"ם, ספינר ועוד), או None לטקסט בלבד.
Controller Server URL הכתובת שאליה התצוגות מתחברות. במחשב בודד להשאיר http://127.0.0.1:5000.

בסיום — SAVE SETTINGS. השינויים נכנסים לתוקף בהפעלה הבאה של הבקר והתצוגות.

7הבקר: העלאת מסכים

בחלק העליון של הבקר מוצגת מפת החדר. כל מסך מופיע כמלבן, ובצידו שלושה ריבועים קטנים המסומנים 4, 2, 1 — מספר החלונות שיוצגו במסך.

פעולהתוצאה
לחיצה על 4 / 2 / 1 מעלה את המסך בפריסה הזו. אם המסך כבר פעיל בפריסה אחרת — הוא נסגר ונפתח מחדש בפריסה החדשה.
לחיצה שנייה על אותו מספרסוגרת את המסך.
לחיצה על גוף המלבן בוחרת את המסך ומפעילה את פאנל Stream Controls למטה.
הבקר לא יעלה תצוגה על המסך שבו חלון הבקר עצמו נמצא. אם לחצתם ולא קרה כלום — הזיזו את חלון הבקר למסך אחר.

8הבקר: מה מוצג בכל ריבוע

אחרי בחירת מסך, פאנל Stream Controls מציג ארבע שורות — אחת לכל ריבוע: Stream 1 (Main), Stream 2 (Right), Stream 3 (Bottom L), Stream 4 (Bottom R).

  • בוחרים מקור מהרשימה הנפתחת — השינוי מופיע במסך מיידית.
  • בחירת None מרוקנת את הריבוע ומחזירה אותו לאנימציית ההמתנה.
  • כפתור ⤢ מגדיל את הריבוע למסך מלא. לחיצה נוספת חוזרת לרשת.
  • כפתור snapshots מצלם את הריבוע ושומר אותו בתיקיית snapshots.
צילומים נשמרים בשם Snap_<מסך>_Quad<מספר>_<תאריך-שעה>.png. OPEN SNAPSHOTS FOLDER פותח את התיקייה.
הערה: הצילום מתבצע מהמסך עצמו, ולכן חלון התצוגה חייב להיות גלוי ולא מוסתר מאחורי חלון אחר.

9הבקר: סצנות

סצנה שומרת את התמונה המלאה — מה מוצג בכל ריבוע בכל מסך, ובאיזו פריסה.

SAVEשומר את המצב הנוכחי. אפשר לסמן שהסצנה תיטען אוטומטית בכל הפעלה של הבקר.
LOADמעלה סצנה שמורה. מסכים שלא נכללים בה מתרוקנים, ומסכים שהפריסה שלהם שונה נסגרים ונפתחים מחדש.
RENAMEשינוי שם, וגם קביעה של סצנת ברירת המחדל.
DELמחיקת הסצנה הנבחרת.
בטעינת סצנה המערכת שולחת את המצב שוב כמה פעמים לאורך שש שניות, כדי לתפוס גם מסכים שעדיין באמצע ההפעלה. זה נורמלי.

10הבקר: השחרה וסגירה

  • BLACKOUT ALL SCREENS — משחיר את כל המסכים מיידית בלי לסגור אותם. הכפתור הופך ל-RESTORE SCREENS; לחיצה נוספת מחזירה את התצוגה בדיוק כפי שהייתה.
  • Help — חלון עזרה מקוצר.
  • Quit — סוגר את הבקר. חלונות התצוגה הפתוחים נשארים פתוחים.

11חלון התצוגה

חלון התצוגה נפתח במסך מלא ואין לו סרגל כותרת של Windows.

  • לסגירה: לוחצים על הכיתוב הקטן oT בפינה התחתונה.
  • ריבוע בלי מקור מציג את אנימציית ההמתנה עם הכיתוב WAITING FOR SIGNAL....
  • אם Show Viewer Header פעיל — יש סרגל עליון עם שם המקור וידית לשינוי גודל החלון. הגודל נשמר לפי הפריסה לפעם הבאה.

12עבודה בכמה מחשבים

אפשר להריץ תצוגות על מחשבים נוספים ברשת, כשהבקר נשאר במחשב אחד.

  1. במחשב הבקר — לברר את כתובת ה-IP שלו ברשת.
  2. במחשב המרוחק — להעתיק את viewer.exe ואת קובצי ההגדרות לתיקייה משלו.
  3. בקובץ config.txt של המחשב המרוחק לשנות את server_url לכתובת הבקר, למשל http://192.168.1.10:5000.
  4. להפעיל שם את viewer.exe עם שם המסך ומספר החלונות.
פורט 5000 חייב להיות פתוח בחומת האש של מחשב הבקר, ושני המחשבים חייבים להיות באותה רשת.
