# חיווט וחיבורים

## מסלול א' (Tello) – אין חיווט
ה-Pi והרחפן מדברים דרך WiFi. ה-Pi מתחבר לרשת ה-WiFi של ה-Tello, שולח פקודות
UDP לפי ה-SDK. אין הלחמות. פשוט מפעילים את שניהם.

## מסלול ב' (DIY) – חיבור Pi ↔ בקר טיסה

### חיבור נתונים: UART (MAVLink)
זה הקו שדרכו ה-Pi שולח פקודות מהירות לבקר הטיסה.

```
Raspberry Pi                 בקר טיסה (FC)
  GPIO14 (TXD) ───────────▶  RX (טלמטריה, למשל TELEM2)
  GPIO15 (RXD) ◀───────────  TX
  GND         ─────────────  GND   (חובה חיבור אדמה משותף!)
```
- קצב מומלץ: `921600` או `57600` baud (התאימו בשני הצדדים).
- **אל תחברו 5V בין המכשירים על קו הנתונים.** רק TX/RX/GND.
- חלופה קלה: כבל USB-to-UART (FTDI) במקום פיני ה-GPIO — פחות סיכוי לשגיאות מתח.

### הזנת חשמל ל-Pi
- אל תזינו את ה-Pi ישירות מ-LiPo (4S = ~16.8V). ישרוף אותו.
- השתמשו ב-**BEC / regulator ל-5V/3A** מהסוללה אל פיני ה-5V/GND של ה-Pi.

### מצלמה
- Pi Camera → מחברת CSI ייעודית ב-Pi (כבל שטוח). אין חיווט ידני.
- מצלמת USB → כל שקע USB.

### מקלט RC וה-kill switch (חובה!)
- מקלט ה-RC מתחבר לבקר הטיסה (לא ל-Pi).
- הגדירו ב-ArduPilot/PX4:
  - ערוץ למעבר בין מצבי טיסה: `STABILIZE` / `LOITER` / `GUIDED`.
  - **מתג kill/failsafe** שמעביר מיד ל-`LOITER` או מבצע `Land`, כך שאתם תמיד
    יכולים "לחטוף" שליטה מה-Pi. זה קו ההגנה הכי חשוב.

## סדר הפעלה מומלץ
1. חברו סוללה, ודאו שהבקר עלה ויציב (בלי פרופלורים בבדיקה ראשונה!).
2. ודאו שהשלט מחובר ושה-kill switch עובד.
3. הפעילו את ה-Pi, ודאו שיש קישור MAVLink (`mavlink_drone.py` ידפיס heartbeat).
4. רק אחרי שהכל תקין ובדוק בסימולציה — הרכיבו פרופלורים וטוסו בשטח פתוח.

## דיאגרמת מתח מסכמת
```
LiPo 4S ─┬─▶ ESC ─▶ מנועים
         ├─▶ בקר טיסה (יש לו BEC פנימי לרוב)
         └─▶ BEC 5V ─▶ Raspberry Pi ─▶ מצלמה
בקר טיסה ◀── UART (TX/RX/GND) ──▶ Raspberry Pi
בקר טיסה ◀── מקלט RC (שלט + kill switch)
```
